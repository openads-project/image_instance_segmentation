image_instance_segmentation


ROS 2 Image Instance Segmentation for Automated Driving

This OpenADS service performs image instance segmentation through Triton Inference Server. It supports multiple cameras, optional tracking, segmentation masks, 2D detections, and debug overlays. Model weights and datasets are supplied separately.

🚀 Quick Start

Run the demo with Triton, recorded camera images, and a segmentation overlay viewer:

cd demo
xhost +local:
docker compose up -d

See the demo README for requirements, configuration, and shutdown. Compose and Helm templates are available for deployment.

💻 Development

Set up Development Environment

  1. Clone the repository.
    git clone https://github.com/openads-project/image_instance_segmentation.git
  1. Initialize the .openads-dev-environment submodule containing development environment configuration.
    cd image_instance_segmentation
    git submodule update --init --recursive
  1. Open the repository in Visual Studio Code.
    code .
  1. Install the recommended VS Code extensions.

    ‍Ctrl+Shift+P / Extensions: Show Recommended Extensions / Install Workspace Recommended Extensions (Cloud Download Icon)

  1. Reopen the repository in a Dev Container. Ctrl+Shift+P / Dev Containers: Rebuild and Reopen in Container

Build

‍Ctrl+Shift+B

colcon build

Run Tests

‍Ctrl+Shift+P / Tasks: Run Test Task

colcon build --cmake-args -DCMAKE_EXPORT_COMPILE_COMMANDS=1
colcon test
colcon test-result --verbose
